# Instrucciones para agentes

- Lee `CODEX_HANDOFF.md` y revisa `git status` antes de modificar el proyecto.
- Conserva tanto el despliegue de Netlify como el de GitHub Pages salvo que el usuario indique lo contrario.
- Después de cada cambio material, actualiza `CODEX_HANDOFF.md` con la fecha, los cambios, las pruebas realizadas, los problemas conocidos y el siguiente paso.
- No afirmes que un despliegue externo funciona si no se ha comprobado en ese proveedor.
